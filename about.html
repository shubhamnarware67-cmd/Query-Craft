About QueryCraft

A modern, dependency-free SQL learning platform built by Shubham Narware.

Why QueryCraft?

SQL is usually taught as a list of syntax rules. QueryCraft teaches it as a language for asking questions of real data — starting from "what is a database" and ending at production-level query optimization, security, and system design.

Built by

Shubham Narware — creator of QueryCraft, built with plain HTML, CSS, and vanilla JavaScript, with no frameworks, to stay fast and dependency-free.

A note on the playground

The SQL Playground is a browser-based learning simulator. It is not connected to a real MySQL server — it's built to teach query logic safely, in any browser, with no setup.
